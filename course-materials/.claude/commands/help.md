The student needs help. Give them a friendly orientation:

1. **Check their progress.** Read `CLAUDE.md` at the project root for the `## Progress` section to understand where they are in the course.

2. **Remind them of available commands.** Show them this list:

```
Available lesson commands:
  /start-1-1  through  /start-1-8   → Module 1 lessons
  /start-2-1  through  /start-2-5   → Module 2 lessons
  /start-3-1  through  /start-3-3   → Module 3 lessons (Power User Track)
  /start-bonus                       → The Gauntlet bonus project
  /stuck                             → Diagnostic flow if you're lost
  /help                              → This menu
```

3. **Offer specific help.** Ask: "What are you trying to do? I can help you navigate to the right lesson, troubleshoot an error, or just answer a question."

4. **If they just want to keep going** — tell them their last completed lesson and suggest the next one with the command to start it.

Always be warm and encouraging. Getting stuck is normal. That's what `/help` is for.
