## Module 3: Power User Track

- **Time to Complete:** 1.5–2 hours
- **Prerequisites:** Module 1 (required), Module 2 (recommended)

Most Claude Code users stop at the basics. This module covers the features that separate power users from everyone else.

## What You'll Learn

| Lesson | What it covers |
|--------|----------------|
| **3.1: Hooks & Automation** | Set rules that run automatically on every action — no asking required |
| **3.2: MCP Deep Dive** | Connect Claude to GitHub, Notion, Google Calendar, Slack, and more |
| **3.3: Multi-Agent Workflows** | Orchestrate parallel agents for complex multi-step tasks |

## Why This Matters

Module 1 taught you to work with Claude. Module 2 taught you to build with Claude.

Module 3 teaches you to **automate with Claude** — setting up systems that run themselves.

- **Hooks** = standing orders. "Always do X when Y happens." Set once, runs forever.
- **MCP** = connections. Claude reaches into your real tools and pulls live data.
- **Multi-agent** = pipelines. Complex tasks broken into parallel streams, orchestrated automatically.

Together, they turn Claude Code from a powerful assistant into a powerful system.
