## What Is MCP?

**Model Context Protocol** — the standard that lets Claude connect to external services.

Without MCP, Claude only knows what you paste into the conversation.

With MCP, Claude can reach into GitHub, read a Notion doc, check your calendar, or query a database — directly, in real time.

## How It Works

MCP servers are small adapters that translate between Claude and an external service. You install them once. After that, Claude uses them silently.

```
Claude Code ←→ MCP Server ←→ GitHub / Notion / Calendar / etc.
```

## Setup Command

```bash
claude mcp add [name] -- [server command]
```

List what's connected:
```bash
claude mcp list
```

## Popular MCP Servers

| Service | Setup Command |
|---------|---------------|
| **GitHub** | `claude mcp add github -- npx -y @modelcontextprotocol/server-github` |
| **Notion** | `claude mcp add notion -- npx -y @modelcontextprotocol/server-notion` |
| **Google Calendar** | `claude mcp add gcal -- npx -y @modelcontextprotocol/server-google-calendar` |
| **Slack** | `claude mcp add slack -- npx -y @modelcontextprotocol/server-slack` |
| **Linear** | `claude mcp add linear -- npx -y @modelcontextprotocol/server-linear` |
| **Jira** | `claude mcp add jira -- npx -y @modelcontextprotocol/server-jira` |
| **Postgres** | `claude mcp add postgres -- npx -y @modelcontextprotocol/server-postgres` |
| **Filesystem** | `claude mcp add filesystem -- npx -y @modelcontextprotocol/server-filesystem /path` |

Search for more: [npmjs.com/search?q=@modelcontextprotocol](https://www.npmjs.com/search?q=%40modelcontextprotocol)

## API Keys

Most MCP servers need an API key from the service. The pattern is always:

1. Generate a key in the service's settings (look for "API", "Integrations", or "Developer")
2. Set it as an environment variable before running Claude:
   ```bash
   export NOTION_API_KEY="your-key-here"
   export GITHUB_TOKEN="your-token-here"
   ```
3. Or add it to your shell profile (`.zshrc`, `.bashrc`) so it's always set

Never paste API keys directly into Claude conversations.

## Troubleshooting

| Problem | Fix |
|---------|-----|
| Server not showing in `mcp list` | Re-run the `claude mcp add` command |
| "Unauthorized" errors | Check your API key is set and correct |
| Server connects but returns nothing | Check the service permissions (Notion needs pages shared with integration) |
| Google Calendar auth loop | OAuth requires a browser flow — follow all prompts carefully |
